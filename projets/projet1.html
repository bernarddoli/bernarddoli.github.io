Casseur de Mots de Passe

Hacking Éthique Python Cryptographie

Outil de test de robustesse des mots de passe développé en Python, combinant attaque par dictionnaire, brute force et règles de mutation. Réalisé dans un cadre strictement éthique et pédagogique.

Introduction

Ce projet a été développé dans le cadre de mon apprentissage du hacking éthique. L'objectif est de comprendre comment les attaquants tentent de retrouver des mots de passe, afin de mieux défendre les systèmes contre ces techniques.

⚠ Avertissement : Cet outil est réalisé dans un cadre légal et pédagogique uniquement. Tout test doit être effectué sur des systèmes vous appartenant ou pour lesquels vous disposez d'une autorisation écrite explicite.

Contexte & Objectifs

Dans le cadre de ma formation en cybersécurité à l'ESI, j'ai souhaité mettre en pratique les notions de cryptographie et d'attaques sur les mots de passe. Les objectifs principaux étaient :

  • Comprendre les différentes méthodes d'attaque sur les mots de passe
  • Implémenter un outil fonctionnel en Python
  • Mesurer la robustesse de différents types de mots de passe
  • Sensibiliser à l'importance des bonnes pratiques de sécurité

Fonctionnement

L'outil est structuré en trois modules principaux, chacun correspondant à une stratégie d'attaque différente.

Attaque par dictionnaire

L'attaque par dictionnaire teste une liste de mots de passe courants (noms, dates, mots simples). C'est la méthode la plus rapide et la plus efficace contre les mots de passe faibles. Elle repose sur des wordlists comme rockyou.txt qui contiennent des millions d'entrées.

Brute force

Le brute force génère toutes les combinaisons possibles de caractères jusqu'à une longueur définie. Efficace mais exponentiellement lent au-delà de 6-7 caractères sans ressources GPU.

Règles de mutation

Le module de mutation applique des transformations courantes sur les mots du dictionnaire : substitutions (a→@, e→3, o→0), ajout de chiffres en fin de mot, mise en majuscule de la première lettre, etc.

Module d'attaque par dictionnaire :

import hashlib

def attaque_dictionnaire(hash_cible, fichier_dico):
    """Teste chaque mot du dictionnaire contre le hash cible."""
    with open(fichier_dico, 'r', encoding='utf-8', errors='ignore') as f:
        for ligne in f:
            mot = ligne.strip()
            hash_test = hashlib.md5(mot.encode()).hexdigest()
            if hash_test == hash_cible:
                return mot  # Mot de passe trouvé !
    return None  # Non trouvé dans le dictionnaire

Module brute force avec itertools :

import itertools
import string

def brute_force(hash_cible, longueur_max=6):
    """Génère toutes les combinaisons jusqu'à longueur_max."""
    charset = string.ascii_lowercase + string.digits
    for longueur in range(1, longueur_max + 1):
        for combo in itertools.product(charset, repeat=longueur):
            mot = ''.join(combo)
            if hashlib.md5(mot.encode()).hexdigest() == hash_cible:
                return mot
    return None

Résultats & Tests

Les tests ont été effectués sur une machine virtuelle Kali Linux, avec une liste de hashes MD5 générés localement à partir de mots de passe connus.

  • Mots de passe simples (< 6 car.) : retrouvés en moins de 2 secondes
  • Mots du dictionnaire : 95 % retrouvés en moins d'une minute
  • Avec mutations : +12 % de taux de succès supplémentaire
  • Mots complexes (> 10 car. mixtes) : non retrouvés (temps prohibitif sans GPU)
Conclusion des tests : Un mot de passe d'au moins 12 caractères combinant majuscules, minuscules, chiffres et symboles résiste efficacement à toutes les attaques testées. L'usage d'un gestionnaire comme KeePass est fortement recommandé.

Limites & Éthique

Ce projet présente plusieurs limitations importantes :

  • Performance limitée en Python pur — pas d'accélération GPU
  • Fonctionne uniquement sur des hashes non salés (MD5, SHA1)
  • Wordlists limitées en taille pour des raisons d'espace disque
  • Usage strictement réservé aux tests sur ses propres systèmes

Conclusion

Ce projet m'a permis de comprendre concrètement les mécanismes d'attaque sur les mots de passe et l'importance de politiques de sécurité rigoureuses. Il illustre parfaitement pourquoi l'utilisation d'un gestionnaire de mots de passe comme KeePass et l'adoption d'une politique de mots de passe forts sont indispensables dans tout environnement professionnel ou personnel.

Ce projet s'inscrit dans ma démarche globale d'apprentissage du pentest et du hacking éthique, en combinant compréhension théorique des attaques et implémentation pratique des outils.
